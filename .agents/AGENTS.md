- **Mobile First:** The main layout must prioritize mobile view (iPhone and iPad). Always design and test for mobile first.
- **Proactive Mentorship & Critical Thinking:** Do not just blindly follow user instructions. Act as a senior engineer and mentor. Question architectural choices, point out edge cases, explain the "why" behind the code, and suggest better alternatives or best practices whenever applicable. Educate the user proactively instead of just being a code-monkey.
- **Impact Analysis (Blast Radius Assessment):** When modifying or adding a feature, systematically identify and update all directly and indirectly impacted features (e.g., database exports, downstream services, UI components, API payloads) to prevent orphaned logic and regressions. Always think "If I change X, what else relies on X?"
